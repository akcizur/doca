# DarkDocs Pro

Production-oriented API documentation template for `akcizur/doca`.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS v4
- Prism.js syntax highlighting
- Lucide icons
- GitHub Pages deployment

## Features

- Cmd/Ctrl + K documentation search
- Responsive documentation sidebar and mobile navigation
- ScrollSpy right-hand table of contents
- Anchor links for documentation sections
- Endpoint accordions
- cURL / JavaScript / Python examples
- Copy-to-clipboard feedback
- Interactive **Try it** request panel
- Local API-key storage with security warning
- API version selector
- Dark/light theme
- Reduced-motion support

## Local development

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

The GitHub Pages workflow builds with `/doca/` as the production base path.
